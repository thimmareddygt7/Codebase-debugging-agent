How this works

Work through the steps on the left, in order. Each step has a short explanation and a form.

Fix automatically
The agent reproduces a failing test, tries a fix on a private copy of your code, and re-runs the tests. Your real code is not changed.
Index
The agent reads your repository and stores it so it can be searched. Do this once per repository.
Run
One investigation by the agent. It gets an ID so you can look at its result and its steps later.
Fix
A proposed code change. It gets its own ID. Nothing changes until you apply it.
Diff
The exact lines a fix would change. Green lines are added. Red lines are removed.
Approve / Reject
Your decision on a proposed fix.
Apply / Roll back
Apply makes the change. Roll back undoes it.
Audit log
A record of what was proposed, approved and applied.

Tip: Ctrl+Enter (or Cmd+Enter) in a text box runs that form. Developers can open the API docs from the top bar.
